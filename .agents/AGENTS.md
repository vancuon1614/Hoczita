# Rules & Guidelines

- **Yêu cầu build APK:** Chỉ thực hiện biên dịch/build file APK khi có yêu cầu trực tiếp từ người dùng. Không tự động build sau mỗi lần sửa code trừ khi được yêu cầu.
- **Yêu cầu push Git:** Chỉ thực hiện push code lên git khi người dùng có ghi chú rõ ràng yêu cầu: "hãy push lên git". Không tự động push sau mỗi lần sửa code hoặc commit.
- **Giao diện độ khó Mini-game:** Tuyệt đối không gắn các icon/emoji không cần thiết (như 🌱, ⚡, 👑, v.v.) tại các mức độ (dễ, trung bình, khó / khởi động, tập trung, thử thách) trong các mini-games. Giữ nhãn tab và chế độ độ khó ở dạng văn bản tinh tế, chuyên nghiệp.
